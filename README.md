Goal

StudyPack is an Audio Analysis Service that turns lecture recordings into study materials. Students often record classes but rarely listen to them again, because a full lecture is too long to review. StudyPack gives them a short, structured version they can actually study from.

Use case

A student records a lecture with their device's microphone, or uploads a recording they already have. They get a job ID and can close the app. Later, they enter the job ID to see the results.

It's useful for:

reviewing a lecture before an exam
catching up on a missed class
checking that you understood the main ideas
Information it produces

For every recording, StudyPack produces:

Transcript: the full text of the lecture
Summary: a short overview of what the lecture covered
Key concepts: the main terms, each with a simple definition
Quiz: 5 questions with answers so the student can test themselves
Topics to review: the parts worth studying again

It also shows the job status (queued, processing, completed or failed). If something goes wrong, for example the audio is empty or in the wrong format, it shows a clear error message.
